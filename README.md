# Milionerzy: Droga do Mistrza Ubrań

Gra quizowa dla uczniów o włókiennictwie, szyciu i oznaczeniach na metkach.

## Jak działa

- 30 pytań: 10 łatwych, 10 średnich, 10 trudnych.
- Pytania mieszają się w obrębie poziomów.
- Uczniowie wpisują dane dwóch osób: imię i numer z dziennika.
- Po zakończeniu wynik zapisuje się w lokalnym zestawieniu na urządzeniu.
- Zestawienie można skopiować jako CSV.

## Uwaga o wynikach

Gra jest statyczną stroną HTML/JS. Na GitHub Pages wyniki zapisują się lokalnie na konkretnym tablecie lub komputerze. Wspólne automatyczne zbieranie wyników ze wszystkich urządzeń wymagałoby osobnej bazy, formularza albo arkusza online.
